# Imágenes Pendientes

Esta carpeta debe contener las siguientes imágenes hero:

- `hero-todos.jpg` - Imagen principal del héroe en formato JPG
- `hero-todos-1200.jpg` - Imagen del héroe optimizada para 1200px de ancho
- `hero-todos.webp` - Imagen del héroe en formato WebP para mejor rendimiento

## Imagen proporcionada por el usuario

La imagen hero debe ser la proporcionada por el usuario (referencia en el PR).

## Notas

Estas imágenes están referenciadas en el service worker (`sw.js`) y se cachearán automáticamente cuando estén disponibles.
